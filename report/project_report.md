# Week 6 Internship Project Report

## Interactive Sales Dashboard

### 1. Project Overview

The Interactive Sales Dashboard is a Python-based data analytics project developed to analyze sales performance through statistical and interactive visualizations.

The project uses Pandas for data processing, Seaborn and Matplotlib for statistical charts, and Plotly for interactive dashboard development.

### 2. Project Objectives

- Analyze sales performance across products and regions.
- Identify trends and patterns in sales data.
- Create statistical visualizations using Seaborn.
- Develop an interactive dashboard using Plotly.
- Present business insights through visual storytelling.

### 3. Dataset Description

The dataset contains 100 records and seven columns: Date, Product, Quantity, Price, Customer_ID, Region, and Total_Sales.

Data quality checks confirmed that the dataset contains no missing values or duplicate records.

### 4. Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
- Visual Studio Code

### 6. Visualization Analysis

**Revenue by Product:** The Laptop category generated the highest revenue at $3,889,210.

**Sales Distribution Box Plot:** Used to examine the variation in individual sales amounts across products and identify potential outliers.

**Correlation Heatmap:** Quantity and total sales showed a positive correlation of 0.69, while price and total sales showed a positive correlation of 0.65.

**Daily Sales Trend:** Visualized daily revenue fluctuations from January to April 2024.

**Revenue by Region:** North generated the highest revenue at $3,983,635, followed by South, East, and West.

### 7. Interactive Dashboard

The Plotly dashboard combines four visualizations into a two-by-two layout:

1. Product revenue comparison
2. Regional revenue comparison
3. Daily sales trend
4. Sales distribution by product

The dashboard includes hover interactions and key performance indicators.

### 8. Testing and Validation

### 9. Key Findings

- Laptops contributed the highest total revenue among products.
- The North region recorded the highest sales revenue.
- Revenue showed daily fluctuations throughout the analysis period.
- Both quantity and price were positively correlated with total sales.
- Interactive visualizations made sales comparisons easier to explore.
