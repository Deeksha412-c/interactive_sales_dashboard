# Interactive Sales Dashboard 📊

## Project Overview

The Interactive Sales Dashboard is a Python-based data visualization project developed as part of Week 6 of my virtual internship.

The project analyzes sales data using Pandas and creates statistical visualizations with Seaborn and interactive charts with Plotly. The dashboard helps users explore product performance, regional revenue, daily sales trends, and sales distributions.

## Project Objectives

- Analyze sales data using Pandas.
- Create statistical visualizations using Seaborn.
- Understand correlation heatmaps and box plots.
- Build interactive charts using Plotly.
- Present key sales metrics in a dashboard layout.
- Document and organize a Python data analytics project.

## Technologies Used

- Python 3
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dashboard Features

### Key Performance Indicators

The dashboard displays:
- Total revenue
- Total units sold
- Number of unique products
- Number of regions

### Visualizations

1. **Revenue by Product:** Compares total revenue generated by each product.
2. **Sales Distribution by Product:** Uses a box plot to show the distribution of individual sale amounts.
3. **Correlation Heatmap:** Shows the linear relationships between quantity, price, and total sales.
4. **Daily Sales Trend:** Displays daily revenue over time.
5. **Revenue by Region:** Compares revenue across different regions.
6. **Interactive Product Chart:** Uses Plotly to display product revenue with hover details.
7. **Interactive Dashboard:** Combines product revenue, regional revenue, daily sales trends, and sales distributions into one layout.

## Dataset

The dataset contains 100 sales records with seven columns:

- `Date`
- `Product`
- `Quantity`
- `Price`
- `Customer_ID`
- `Region`
- `Total_Sales`

## Key Findings

- **Total revenue:** $12,365,048.00
- **Total units sold:** 478
- **Number of products:** 5
- **Number of regions:** 4
- **Top-performing product by revenue:** Laptop
- **Highest-revenue region:** North

### Correlation Analysis

The correlation matrix shows:
- Quantity and price have almost no linear correlation (0.01).
- Quantity and total sales have a positive correlation (0.69).
- Price and total sales have a positive correlation (0.65).

Correlation indicates association, not causation.

## Setup Instructions

### 1. Install Python

Download Python from [python.org](https://www.python.org/downloads/).

### 2. Install Dependencies

Open a terminal in the project directory and run:

```bash
pip install -r requirements.txt
```

### 3. Run the Dashboard Script

```bash
python dashboard.py
```

The script generates chart images and interactive HTML files in the `visualization/` directory.

### 4. Open the Interactive Dashboard

Open `visualization/interactive_dashboard.html` in a web browser.

You can hover over chart elements to inspect values.
